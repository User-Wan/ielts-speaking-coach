# 05｜第一阶段验收标准

## 功能

- [ ] 测试用户可以登录和退出
- [ ] 登录后可以读取属于自己的课程
- [ ] 点击课程可以创建新的训练会话
- [ ] 同一用户不能读取其他用户的训练会话
- [ ] 陪练房可以录制并上传一段音频
- [ ] 后端可以返回模拟或真实的转写结果
- [ ] 后端可以返回结构稳定的模拟 AI 回复
- [ ] 当前训练步骤和进度能够保存
- [ ] 刷新页面后可以恢复训练
- [ ] 保存退出后课程显示“待继续”
- [ ] 完成后课程显示“已完成”

## 工程交付

- [ ] 提供数据库结构和迁移文件
- [ ] 提供 OpenAPI 或等价接口文档
- [ ] 提供 `.env.example`，不包含真实密钥
- [ ] 提供测试账号和种子数据
- [ ] 提供本地启动说明
- [ ] 提供接口自动化测试
- [ ] 密钥只存在于服务端环境变量
- [ ] 开发、测试和生产环境彼此隔离

## 暂不验收

- 正式短信验证码
- 正式支付
- 正式课时扣减
- 最终 AI 教练提示词
- 最终训练步骤与过关算法
