# Lindsey AI 提分教练｜技术开发交接包 v1

交接日期：2026-08-09

## 这份包的用途

这是一份供技术开发同事启动正式前后端开发的交接材料。当前页面属于高保真产品原型，不是正式生产代码。

产品负责人将继续设计 AI 陪练房的完整训练流程；技术负责人可以先完成与具体流程无关的工程底座、账号、课程、训练会话、录音上传、数据库和 AI 服务适配层。

## 目录

- `prototype/`：当前确认的页面原型与视觉素材
- `reference-screenshots/`：关键页面效果图
- `docs/01-scope-and-roles.md`：任务边界与协作方式
- `docs/02-stable-product-contract.md`：现阶段可确认的产品合同
- `docs/03-data-model.md`：数据库对象草案
- `docs/04-api-draft.md`：API 接口草案
- `docs/05-acceptance-criteria.md`：第一阶段验收标准
- `api/openapi.yaml`：可用于后端脚手架的 OpenAPI 初稿
- `samples/session.json`：训练会话示例数据

## 当前页面链路

```text
产品主页 → 登录 → 我的课程 → AI 陪练房 → 保存/完成 → 返回我的课程
```

目前原型中的部分按钮只做了视觉或模拟交互，技术实现不能把静态 HTML 中的假数据当成正式业务规则。

## 技术开发的第一阶段目标

测试用户能够登录、读取课程、创建训练会话、录制并上传一段音频、获得模拟转写与模拟 AI 回复、保存进度，并在刷新后继续训练。

## 重要限制

- 不要在前端保存模型、语音、短信或数据库密钥。
- 不要写死训练步骤数量、步骤名称或过关规则。
- `currentStepKey`、`progressData` 和 `metadata` 必须允许后续扩展。
- AI 提示词、步骤推进规则和课时扣减规则等待产品负责人确认。
